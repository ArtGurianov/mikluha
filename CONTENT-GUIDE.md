# Контент SSR-сайта

Каталог сайта читается из опубликованной public projection Commerce на каждом запросе.
Редактор — отдельный Control Room; `/admin` на публичном сайте удалён. Сохранение черновика
не публикует его. Публикация каталога не требует GitHub, YAML commit или пересборки сайта.

До квалификации новой БД, резервного копирования и изолированного восстановления не вносите
реальные Admin/content/legal данные. Продажи CLOSED. TOUR-59 владеет переносом настроек и legal;
пока `content/site-settings.yml` и `content/legal/` — проверяемые read-only входы code release.
`test-fixtures/catalog/` — демонстрационные данные только для тестов.

Изменения цен, договоров, мест и опубликованных редакций выполняются по каноническим
контрактам Commerce. Редактор не получает DB, GitHub, банковские или S3 writer credentials.
