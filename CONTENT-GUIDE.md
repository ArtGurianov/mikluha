# Памятка по управлению сайтом «Миклуха Маклай»

Весь контент сайта редактируется на странице `/admin` — отдельной админ-панели (Sveltia CMS), доступ к которой вам выдаст разработчик (нужен аккаунт на GitHub с доступом к репозиторию сайта). После сохранения изменений сайт обновляется не мгновенно — обычно в течение нескольких минут (автоматическая пересборка).

При первом входе откроется окно GitHub — подтвердите вход своим GitHub-аккаунтом. Если вы впервые загружаете фото/файл через `/admin`, панель один раз попросит ввести ключ доступа к хранилищу изображений — его выдаст разработчик, вводится один раз и остаётся только в вашем браузере.

**Демо-фото временно выглядят «битыми» в панели.** Пока направления/выезды/отзывы не заменены на настоящие, их обложки и галереи открыть/поменять прямо в `/admin` нельзя (это тестовые файлы, зашитые в саму сборку, а не в хранилище изображений) — предпросмотр покажет пустую иконку. Это нормально: при первой же замене фото на реальное всё работает как обычно — новый файл сразу загружается в хранилище и виден в панели.

## Разделы админ-панели

- **Настройки сайта** — название, логотип, главный экран, реквизиты компании, QR/сумма предоплаты и контакт по умолчанию, ссылка на MAX.
- **Туры** — направления (Алтай, Столбы и любые новые).
- **Выезды** — конкретные даты внутри направления.
- **Отчёты** — фотоотчёты о прошедших поездках.
- **Отзывы** — скриншоты переписки с участниками.
- **Организаторы** — карточка организатора (имя, фото, телефон, био).
- **Правовые страницы** — «Условия бронирования», «Политика конфиденциальности» и любые другие, которые понадобятся.

## Частые задачи

**Изменить дату выезда.** Раздел «Выезды» → открыть нужный выезд → изменить «Дата начала»/«Дата окончания» → Save changes.

**Открыть/закрыть набор.** В том же выезде — поле «Статус набора»: «Набор открыт» / «Набор закрыт» / «Поездка отменена». Отменённая поездка автоматически перестаёт предлагаться на сайте, но история сохраняется.

**Добавить новый выезд.** Раздел «Выезды» → New Выезд → выбрать направление, даты, статус → при необходимости указать свою сумму предоплаты/QR/организатора (если не указывать — подставятся значения по умолчанию из «Настроек сайта»).

**Загрузить отчёт о поездке.** Раздел «Отчёты» → New Отчёт → указать направление и (если есть) связанный выезд, загрузить обложку и галерею фото.

**Заменить QR-код или сумму предоплаты.** По умолчанию для всех выездов — в «Настройках сайта» → «Бронирование». Для конкретного выезда — прямо в документе выезда (переопределяет значение по умолчанию).

**Заменить контактный телефон.** Телефон организатора — в разделе «Организаторы». Телефон компании (для футера) — в «Настройках сайта» → «Реквизиты».

**Добавить новое направление.** Раздел «Туры» → New Тур, заполнить название, описание, фото. Новое направление появится на сайте без участия разработчика.

**Добавить правовую страницу.** Раздел «Правовые страницы» → New, заполнить адрес страницы латиницей — `public-offer` → страница откроется по адресу `/public-offer/` и сама появится ссылкой в футере. Разработчик для этого не нужен. «Условия бронирования» удалять нельзя — на них ссылается бронирование.

## Перед публичным запуском

Пока в «Настройках сайта» выключен переключатель **«Сайт готов к публичному запуску»**, сборка считается демо-версией. Перед тем как его включить:

- [ ] заменены тестовые реквизиты компании и телефон в «Настройках сайта» → «Реквизиты» (снят флажок «Демо-данные»);
- [ ] заменён тестовый организатор на настоящего (снят флажок «Демо-данные»);
- [ ] заменены тестовый QR-код и сумма предоплаты по умолчанию (снят флажок «Демо-данные» в «Бронировании»);
- [ ] у всех выездов, отзывов и организаторов, которые должны быть видны на сайте, снят флажок «Демо-данные»;
- [ ] реальные фото и тексты вместо заглушек с надписью «ТЕСТОВОЕ ИЗОБРАЖЕНИЕ»;
- [ ] проверены тексты «Условий бронирования».

Сборка с демо-данными (`isDemo = true`) не пройдёт как публичный релиз, пока переключатель «Готов к публичному запуску» включён, — это защита от случайной публикации тестового контента.
